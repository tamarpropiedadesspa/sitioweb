# 🏢 Tamar Propiedades SpA — Sitio Web Corporativo & Catálogo Inmobiliario

> Desarrollado e implementado por **[PáginasPro.cl](https://paginaspro.cl)** — Soluciones Web Profesionales & Desarrollo a Medida en Chile.

---

## 📌 Descripción del Proyecto

Aplicación web de alto rendimiento desarrollada para **Tamar Propiedades SpA** (Bienes Raíces e Ingeniería Sostenible). Diseñada para ofrecer una experiencia de usuario fluida tanto en el sector residencial como en servicios corporativos para empresas, integrando un catálogo de inmuebles en tiempo real conectado directamente a Google Sheets y AppSheet.

---

## 🚀 Tecnologías Utilizadas

* **Frontend:** React + TypeScript
* **Estilos & UI:** Tailwind CSS + Lucide React (Iconografía)
* **Base de Datos & Backend:** Google Sheets API + Google Apps Script WebApp
* **Gestión de Datos Móvil:** AppSheet Integration
* **Indicadores Financieros:** API Mindicador (Cotización de UF en tiempo real)
* **Build Tool & Bundler:** Vite / Node.js

---

## ✨ Características Destacadas

* 🔄 **Sincronización Silenciosa:** Actualización automática del catálogo en segundo plano desde Google Sheets cada 60 segundos sin interrumpir la navegación.
* 💱 **Auto-conversión de Divisas UF / CLP:** Conversión dinámica en tiempo real entre UF y Pesos Chilenos según el valor oficial diario.
* 🖼️ **Carga Optimizada & Galería Ambiental:** Miniaturas de respuesta ultra rápida y visualización de imágenes al 100% de escala con marco de fondo difuminado (*ambient blur fill*).
* 📍 **Navegación GPS Multiapp:** Modal inteligente que permite seleccionar la app preferida (Google Maps, Waze, Apple Maps) para llegar a la ubicación exacta de la propiedad.
* 📲 **WhatsApp Directo:** Botones de cotización pre-configurados que envían la ficha completa del inmueble al canal oficial de atención.
* 🎨 **UI/UX Adaptativa:** Diseño 100% responsivo para móviles, tablets y computadores de escritorio.
